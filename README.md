# skills-md

Claude Code skills for Agilize.

## Skills

### agilize-presentation

Create polished, animated HTML slide presentations following the Agilize design system.

**Trigger**: Use when creating presentations, slide decks, or pitch decks.

**Structure**:
- `SKILL.md` — Main skill definition with design system documentation
- `references/design-tokens.md` — CSS custom properties and color palette
- `references/components.md` — Full HTML/CSS component library
- `references/navigation.md` — JavaScript navigation system

## Installation

To install a skill locally:

```bash
cp -r agilize-presentation ~/.claude/skills/
```
